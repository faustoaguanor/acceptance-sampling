# Trámites catastrales — ejemplo ISO 2859-1

`tramites_catastrales_iso2859.csv` contiene 41 registros ficticios de
trámites catastrales. No incluye nombres, cédulas, direcciones reales ni
expedientes oficiales.

## Prueba recomendada

Configure la aplicación con:

- Por atributos;
- inspección normal;
- nivel general II;
- AQL 4,0 %;
- archivo `tramites_catastrales_iso2859.csv`.

El lote tiene `N = 41`, por lo que la letra inicial es `D`. La flecha de la
Tabla 2-A lleva al primer plan por debajo, letra `E`: `n = 13`, `Ac = 1` y
`Re = 2`.

Para probar la muestra estratificada, elija `ADMINISTRACION_ZONAL`. La
asignación es proporcional y la aplicación conserva el detalle en la hoja
`Estratos` del XLSX descargado.
